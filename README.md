# Olympo Store

Tienda de perfumería construida con React, Vite y Supabase.

## Desarrollo local

```bash
npm install
npm run dev
```

La aplicación estará disponible normalmente en `http://localhost:5173`.


## Administración

Inicia sesión en `/admin`. El usuario debe tener `role: "admin"` en `app_metadata` de Supabase.

## Scripts

```bash
npm run dev
npm run build
npm run lint
npm run preview
```
